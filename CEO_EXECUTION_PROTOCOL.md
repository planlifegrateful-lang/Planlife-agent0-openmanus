# CEO EXECUTION PROTOCOL

## Mission
Turn existing Planlife / Limitless assets into a verified cloud business. Finish existing work before creating new products.

## Priority stack
1. Production safety
2. Build/test correctness
3. Cloud deployment
4. End-to-end automation
5. First revenue funnel
6. Scale
7. Strategic Muslim platform expansion

## Non-negotiables
- Never claim a task is complete without evidence.
- Never expose or commit secrets.
- Never put provider API keys in browser storage.
- Preserve working features while hardening production code.
- Prefer cloud execution over local-device dependency.
- Every implementation change must have a PR, tests/build evidence, and a rollback path.
- Block new product work when a production blocker exists in the current priority stack.

## Revenue decision
The first commercial offer will be based on the UGC ad-script/content capability already being built. Start narrow: automated short-form ad/script production for small businesses and creators. Validate demand before building a larger SaaS surface.

## Daily agent loop
AUDIT → SELECT ONE BLOCKER → IMPLEMENT → TEST → REVIEW → DEPLOY → VERIFY → DOCUMENT → NEXT BLOCKER.

## Escalation
If credentials, billing, DNS, deployment permissions, or an external account are required and unavailable to the agent, stop at the exact boundary, document the missing action, and continue all work that does not require the credential. Never fabricate access or success.

## Completion definition
A project is complete only when the user can access the deployed system, execute the primary workflow successfully, and the repository contains reproducible deployment/test instructions.
